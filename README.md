# ValuationSnapshot

Weekly valuation snapshot for major US ETFs and mega-cap stocks — tracking
**P/E**, **P/FCF**, and **EV/EBIT** against 5-year trends. Fully auto-updated
every Saturday **06:00 CST** via GitHub Actions.

- 🌐 **Live site**: <https://iceprincefounder.github.io/ValuationSnapshot/>
- 📅 **Historical snapshots**: [Pages/](Pages/)
- 🛠️ **Source**: [ValuationSnapshot.py](ValuationSnapshot.py) (pure standard library, zero pip)
